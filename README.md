## Pet Submission Page
### Setup Instruction
Backend setup
> To run this project, you need to import the pawpal_db file into the phpMyAdmin. Please ensure that the XAMPP is installed and start Apache and MySQL

Configure Base URL
> open lib/myconfig.dart and update the baseUrl with your IP address
> to find your IP address, write ip config in your CMD (windows)
